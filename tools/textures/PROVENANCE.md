## 進 repo 之前做了什麼

原圖是彩色的。這裡存的是**灰階 + 拉開對比 + 縮到 1024** 的版本:

- **只取表面起伏,不取顏色。** 顏色由 `draw_scenes.py` 的調色盤決定,材質只負責讓平面色塊長出鏽斑跟刮痕。
  直接貼原始彩圖會變成拼貼——三張照片各有各的白平衡,跟畫面上那盞鈉燈打架
- **灰階**因此也讓檔案小得多(三張加起來約 1.4MB,原始 zip 是 15MB)
